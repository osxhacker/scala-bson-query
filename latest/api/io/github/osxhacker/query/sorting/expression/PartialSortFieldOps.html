  •  package expression

    The expression package defines syntactic convenience constructs for defining io.github.osxhacker.query.sorting.SortSpecifications.

    The expression package defines syntactic convenience constructs for defining io.github.osxhacker.query.sorting.SortSpecifications. It is what enables being able to write:

    import io.github.osxhacker.query.sorting
import untyped._

val sortOrder = by (_.first.asc, _.second.desc)

    And have the be the equivalent of:

    val specification = SortSpecification (
    SortField (Field ("first"), ascending = true) ::
    SortField (Field ("second"), ascending = false) ::
    HNil
    )
